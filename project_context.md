
# BashaLagbe — Project Context

## Purpose
An Android rental-house discovery app for Bangladesh.
Helps bachelors, students, families and other renters find
suitable houses without wasting money on unnecessary visits.

## Technology
- Flutter
- Dart
- Android first
- Firebase planned for a later milestone

## Current Project
- Flutter project: basha_lagbe
- Main file: lib/main.dart
- Current stage: initial UI and local demo data

## First Milestone
- Home screen
- Search by area, title and landmark
- Bachelor, Family and Shared filters
- Reusable rental property cards
- Empty search state
- Bottom navigation with clear placeholders

## Future Milestones
1. Property detail screens
2. User authentication
3. Property submission and photo uploads
4. Firebase database integration
5. Listing moderation and reporting
6. Availability confirmation
7. Security testing and Play Store release

## Development Rules
- Keep changes small and testable.
- Explain where every new file belongs.
- Prefer complete files when requested.
- Do not invent real house listings or verification claims.
- Never expose secrets or private user data.
- Run flutter analyze after meaningful code changes.
- Do not change package IDs or build configuration without approval.

## Current Status
The Flutter demo has launched successfully.
